Ceneo XML Feed Validator

Check for free whether your product feed meets Ceneo.pl requirements — before offers get rejected. The file is checked in your browser and is never uploaded anywhere.

No XML file?

Your wholesaler or manufacturer has no feed? We read the supplier's public website every day (prices, stock, EAN) and turn it into a Ceneo-standard XML file — ready for Ceneo, BaseLinker, Apilo or Shoper, with your markup. First test file within 24 hours, free.

Email partners@eupriceindex.com with the supplier's website.

What it checks

  • Structure: valid XML, <offers> root, <group> and <o> offers.
  • Required fields: unique id, full url, price with a dot and above zero, <name>, <cat>.
  • Availability: avail only 1, 3, 7, 14, 90, 99 or 110; whole-number stock; set and basket only 0 or 1.
  • Offer quality: main image, description, manufacturer and EAN — with EAN-8/EAN-13/GTIN-14 check-digit validation.
  • Duplicates: repeated ids and urls.

The feed link only works if the shop's server lets browsers download the file. Otherwise download the file and choose it from your device.

Independent tool, not affiliated with Ceneo.pl. Checks follow Ceneo's public XML file instructions; Ceneo makes the final decision on accepting offers.
